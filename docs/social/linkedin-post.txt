Code + setup: https://github.com/QasimAliSidhu/local-studio

My proposed enterprise roadmap:

1) Separate workspaces for every learner and organization, SSO and learner/instructor/admin permissions.
2) Disposable, isolated code runners with resource limits and network controls; separate AI credentials and per-team budgets.
3) Cohort assignments, instructor dashboards and versioned assessments.
4) Audit logs, data export/deletion controls, monitoring, tested backup restores and load testing.
5) Pilot with one team; measure completion, learning improvement and cost per learner before expanding.

These enterprise capabilities are planned.
