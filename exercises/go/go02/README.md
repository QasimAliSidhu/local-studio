# Count words with maps

Maps must be initialized before assignment. strings.Fields splits on whitespace.

## Your task

`WordCounts(text string) map[string]int` counts case-insensitive whitespace-separated words. Preserve punctuation as part of a word. Empty input returns an empty, non-nil map.
