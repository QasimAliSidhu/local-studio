# Protect the snack fund

## Your mission

- Implement Wallet(balance=0) with read-only balance property.

- Reject negative starting balance or negative deposits with ValueError.

- deposit(amount) adds a non-negative amount and returns the balance.

- Invalid deposits leave state unchanged.

- Inputs are integers.

This is a **function challenge**: Run calls the tests for debugging without completion credit. Follow the function's return-value contract.

**Run** to experiment and debug. **Submit answer** checks your work and saves completion when all checks pass.
