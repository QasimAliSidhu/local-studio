# Mission: the polite rate limiter

## Your mission

- Return a list of bools for users, accepting only the first limit events per distinct user in this batch.

- limit is a non-negative integer.

- Keep input order, do not mutate users, and reset counters for each function call.

This is a **function challenge**: Run calls the tests for debugging without completion credit. Follow the function's return-value contract.

**Run** to experiment and debug. **Submit answer** checks your work and saves completion when all checks pass.
