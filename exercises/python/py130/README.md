# While the queue is still awake

## Your mission

- Implement drain_batches(work, capacity).

- Return (batch_count, remaining).

- work >= 0 and capacity > 0 are integers.

- Each batch handles up to capacity; stop when no work remains.

- Use a while loop to practice state updates.

This is a **function challenge**: Run calls the tests for debugging without completion credit. Follow the function's return-value contract.

**Run** to experiment and debug. **Submit answer** checks your work and saves completion when all checks pass.
