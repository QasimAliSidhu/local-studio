# Slices without paper cuts

## Your mission

Complete `recent_items(values, count)`. `count` is a non-negative integer.

- Return a **new list** containing the last `count` items, in their original order.
- Return `[]` when `count` is `0`.
- When `count` exceeds the length, return a shallow copy of the full list.
- Leave the input unchanged.

This is a **function challenge**: Run calls the tests for debugging without completion credit. Follow the function's return-value contract.

**Run** to experiment and debug. **Submit answer** checks your work and saves completion when all checks pass.
