# Inheritance, with a real reason

## Your mission

- Implement Job(units) with cost() returning units.

- Implement PriorityJob(units, surcharge) inheriting Job, initializing the base, and overriding cost() to return base cost plus surcharge.

- Inputs are non-negative integers.

This is a **function challenge**: Run calls the tests for debugging without completion credit. Follow the function's return-value contract.

**Run** to experiment and debug. **Submit answer** checks your work and saves completion when all checks pass.
