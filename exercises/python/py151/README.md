# Two input types, one honest boundary

## Your mission

- Implement normalize_id(value: int | str) -> int.

- Accept non-negative integers or text parseable by int.

- Reject bool and all other types with TypeError; reject malformed text and negative results with ValueError.

- Keep annotations.

This is a **function challenge**: Run calls the tests for debugging without completion credit. Follow the function's return-value contract.

**Run** to experiment and debug. **Submit answer** checks your work and saves completion when all checks pass.
