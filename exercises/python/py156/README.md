# Mission: the dependency inventory

## Your mission

- Given a dict mapping project names to lists of library names, return a dict counting how many distinct projects use each library.

- Repeats within one project count once.

- Empty projects add no keys.

- Do not mutate input.

This is a **function challenge**: Run calls the tests for debugging without completion credit. Follow the function's return-value contract.

**Run** to experiment and debug. **Submit answer** checks your work and saves completion when all checks pass.
