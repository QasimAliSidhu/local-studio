# Recursion with an exit sign

## Your mission

- Implement nested_sum(node).

- node is an integer or a possibly nested list with the same shape.

- Return the sum of integer leaves.

- Empty lists contribute zero.

- Inputs are finite, acyclic and reasonably shallow.

- Do not mutate them.

This is a **function challenge**: Run calls the tests for debugging without completion credit. Follow the function's return-value contract.

**Run** to experiment and debug. **Submit answer** checks your work and saves completion when all checks pass.
