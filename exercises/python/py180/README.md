# Split the message, join the pieces

## Your mission

- Implement dash_words(text), returning its whitespace-separated words joined with one dash.

- Preserve word spelling and case.

- All-whitespace or empty text returns an empty string.

This is a **function challenge**: Run calls the tests for debugging without completion credit. Follow the function's return-value contract.
