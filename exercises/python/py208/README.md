# Make a tiny database before building storage

## Your mission

- Implement roundtrip_names(names).

- Open an in-memory SQLite database, store each supplied name using bound parameters, read names back in insertion order, and return them as strings in a list.

- Preserve duplicates and punctuation.

- Close the connection before returning.

This is a **function challenge**: Run calls the tests for debugging without completion credit. Follow the function's return-value contract.

**Run** to experiment and debug. **Submit answer** checks your work and saves completion when all checks pass.
