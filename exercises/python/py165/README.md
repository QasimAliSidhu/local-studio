# Pure functions, less cleanup

## Your mission

- Return new {"name", "score"} dictionaries for every input record, sorted by score descending then name ascending.

- Drop other fields.

- Leave the input list and its dictionaries unchanged.

- Names are strings; scores are integers.

This is a **function challenge**: Run calls the tests for debugging without completion credit. Follow the function's return-value contract.

**Run** to experiment and debug. **Submit answer** checks your work and saves completion when all checks pass.
