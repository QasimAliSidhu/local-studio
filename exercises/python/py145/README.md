# Reject nonsense at the boundary

## Your mission

- Implement validate_port(value).

- Accept an int from 1 through 65535 and return it.

- Reject bool and non-int inputs with TypeError.

- Reject out-of-range integers with ValueError.

- Include "port" in each error message.

This is a **function challenge**: Run calls the tests for debugging without completion credit. Follow the function's return-value contract.

**Run** to experiment and debug. **Submit answer** checks your work and saves completion when all checks pass.
