# Python: foundations to backend

**115 interactive lessons across 21 chapters.**

## Start from zero

The opening lessons run plain scripts. Learn what the editor, console, strings and print mean, then change a working example. Variables, numbers and text come next. Custom functions are introduced in separate definition, parameter and return-value lessons before function challenges.

## How to learn

Read the explanation, walk through the example, predict the result, then try the mission. Run executes scripts or runs function tests without completion credit. Submit answer grades the requested behavior and saves completion on success. Ask the tutor whenever a word or line is unfamiliar. Hints come before optional reference solutions. Experiments in Extra practice keep your challenge separate.

## Progression

Foundation chapters teach basic syntax. Core Python adds collections, loops, errors, hints and mutation. Intermediate chapters cover modules, objects and functional tools. Advanced Python patterns include closures, argument forwarding, decorators and context managers. Backend practice applies files, JSON, CSV, SQLite, caching and asynchronous work. This is a learning path through those topics, not a claim that finishing it makes someone an expert in every Python framework.

## Your existing work

Earlier code files are retained. Revised missions use new working filenames so an old function wrapper does not remain in a first-day script. Edited function attempts are carried forward when their contract is unchanged. Old browser drafts remain stored separately by content revision. Completion credit, notes and conversations are retained.
